# Solution: LP-0005 - TokenStudio ProofGate

**Submitted by:** FidelCoder

## Summary

TokenStudio ProofGate is a reusable private LEZ token-balance attestation
primitive with on-chain and off-chain consumers. A Risc0 guest proves that a
committed private fungible-token account belongs to a verifier-authorized LEZ
commitment tree and has `balance >= threshold` without revealing the account
ID, exact balance, nonce, account data, nullifier key, or Merkle path.

The same proof can authorize an encrypted Logos Messaging group or a SPEL gate
that issues a holder-private access badge through the official LEZ private
execution path.

## Approach

The balance proof mirrors LEZ `v0.2.0` commitment and Merkle semantics. It
checks private-account commitment and membership, token definition and program
owner, `balance >= threshold`, application context, presenter public key, and
proof timestamp.

The verifier selects the trusted commitment root. Proof forwarding is
prevented by requiring the presenter to sign a fresh verifier challenge using
the key committed in the proof. Persistent challenge state prevents off-chain
replay. Rotating GateState nonces and counters prevent on-chain replay.

## Privacy And Security

**Hidden:** account identity and exact balance; nullifier key, nonce, and
account data; Merkle path; private badge state; and private signing keys.

**Public:** gate policy and threshold; authorized commitment root; presenter
public key; proof timestamp; and public transaction and GateState identifiers.

ProofGate has not received an independent security audit.

## Impact

ProofGate provides reusable private token gating for communities, governance,
protocol tiers, and membership systems without exposing token holdings or
requiring a centralized verifier.
