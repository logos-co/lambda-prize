## Implementation

### QR Scan (Shell -> dApp)
- AnimatedQRScanner reads Shell crypto-account QR (ERC-4527 UR format)
- CryptoAccount.fromCBOR() parses UR data via @keystonehq/bc-ur-registry
- generateAddressFromXpub() derives ETH addresses

### QR Output (dApp -> Shell)
- AnimatedQRCode displays animated sign request to Shell
- eth-sign-request UR type for EVM signing
- btc-sign-request UR type for Bitcoin signing

### Address Display
- BIP-44 m/44'/60'/0'/0/0 — Ethereum
- BIP-44 m/44'/0'/0'/0/0  — Bitcoin Legacy (P2PKH)
- BIP-49 m/49'/0'/0'/0/0  — Bitcoin Nested SegWit (P2SH-P2WPKH)
- BIP-84 m/84'/0'/0'/0/0  — Bitcoin Native SegWit (P2WPKH)

### Signing
- EIP-191 personal_sign for EVM keys
- BIP-322 for Bitcoin keys
- Signature scan via AnimatedQRScanner
